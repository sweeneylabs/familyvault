# FamilyVault AI

FamilyVault AI is a private, self-hosted photo and video library designed to help families organize, search, and preserve their memories using artificial intelligence.

## Vision

FamilyVault combines modern AI with complete ownership of your data.

Features planned include:

- Intelligent photo and video indexing
- AI-generated captions
- Face recognition
- Duplicate detection
- Timeline view
- Map view
- Natural language search
- Automatic albums
- Local-first storage
- Self-hosted web application
